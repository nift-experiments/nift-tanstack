# Phase 2 AI developer experience

A fresh-context maintenance worker received normal tasks and the checked-in README, not the implementation conversation or injected defect location. Instrumented implementation/check window: 152 seconds. It added two maintained docs, interactive MDX, a shared accessible callout treatment and Vite-imported SVG, an interactive capacity route/view, and fixed Settings navigation. See maintenance-phase2.md for actual discovery and errors.

It edited one shared application and provider-component map, with no Nift HTML template coordination. The new route, view, metadata and docs apply to both models. This is a concrete structural improvement over the preserved Phase 1 maintenance record, which required separate HTML/JSX shell and landing edits.

Actual mistakes remain visible: typed splat-route Link usage was caught by typecheck after successful bundler builds; an SSR text assertion initially ignored React comment delimiters; section display titles needed shared metadata lookup. Both builds/typecheck passed, and parent browser checks then verified components, exact capacity totals and search. The browser evidence is not retroactively attributed to the worker.

The task did not test agent repair of the native dependency adapter, and it is not a blinded comparative productivity study. Phase 1's approximate four-minute duration is not directly comparable to this different 152-second exercise. No percentage productivity improvement is claimed.

The parent implementation also encountered real friction: native syntax discovery, project-boundary assumptions, cache commit ordering, timestamp-vs-hash semantics, test/production JSX environment, watcher roots, Vite output cleanup and MDX prose keyword parsing. These are documented, tested where concrete, and not erased by a successful final handoff.

Judgment: AI-DX improves from the original hybrid 6/10 to 7/10 because source ownership and the one-shell app are clearer. The optimized control remains 8/10 for this project: ordinary maintenance is shared, but its planner avoids an additional language/binary/recipe layer. This is subjective engineering judgment, not a measured agent benchmark.
