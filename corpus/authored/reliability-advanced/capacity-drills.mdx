# Capacity drills before a release

Compare services in the [capacity workspace](/app/capacity) before scheduling a recovery drill. The fixture view totals deployment execution seconds; it is a planning proxy, not measured infrastructure utilization.

<Callout title="Set a review budget" tone="warning">
Choose an execution-time budget for the selected environment. A service over budget needs review before additional deployment work is scheduled; the result does not prove a production outage.
</Callout>

## Review the result

1. Select production in the capacity workspace and compare total seconds, deployment count and average duration.
2. Lower the budget until a service is flagged; check that the review count and headroom change.
3. Record actual request errors and latency separately. Fixture deployment duration cannot establish traffic capacity.
4. Follow the [recovery evidence checklist](/docs/reliability-advanced/recovery-evidence) before closing the drill.
